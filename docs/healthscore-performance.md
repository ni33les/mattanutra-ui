## Changes

- Minify prompt JSON while retaining assessment, safety, catalogue, previous formula, feedback and chat facts. Put the reusable catalogue/instructions before customer-specific data.
- Request strict response shapes for formulation and HealthScore only. Existing semantic validators, historical response readers and bounded retries remain active. Other Grok callers retain JSON-object mode.
- Correct the contradictory `supplement.en` instruction and explain HealthScore's existing per-field number and text-length restrictions before the first call.
- Default HealthScore copy polishing to low reasoning. Formula reasoning stays medium. Advance internal prompt identities; no public MCP change, new locks or database changes.
