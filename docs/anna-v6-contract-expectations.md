# Anna v6 intentional contract expectation changes

Historical reports and the published v4/v5 resources remain unchanged. These replacements apply to the v6 maintained suites; catalogue prices and dose-fit arithmetic are unchanged.

| Existing expectation | V6 replacement | Regression evidence |
| --- | --- | --- |
| `AE-04`, `AX2-05`, `AX2-13`: entire `info` response fits 4096 bytes | Preserve the 4096-byte capability payload bound; separately bound required tools-only instructions/examples at 8192 bytes. Assert all five complete operation templates and explicit supplemental example. Measured instructional payload: EN 7548, TH 7871, ZH 7507 bytes. | `ANNA-AX-01`, `ANNA-AX-08`; shared `infoConversationBudget` |
| `AX4`, `AX2-13` info allow-list contains URI links only | Allow the typed `clientInstructions` and `clientExamples` fields on ordinary info. Optional guide/schema views are documented separately. No private diagnostics are added. | `ANNA-AX-08` |
| `AX2-08` option and `AX3-02`/`AX6-01` revised-plan allow-lists omit numeric preference assessment | Add only typed `preferenceAssessment`; preserve option deduplication, selection revision and no-rematch assertions. Unspecified preferences produce no unsolicited advice rows, retaining existing response size limits. | `ANNA-AX-09` |
| `FIX-06` description claims installed connector equality | Keep its registry/snapshot/checksum assertions and state their actual scope. An independent validator requires genuine installed-connector export evidence and rejects native/local stand-ins. | `ANNA-AX-06`, `ANNA-AX-07` |
| Current resource count is four; current version is 5.0.0 | Current v6 plus immutable guide/schema resources for both v4 and v5: six resources. Explicitly assert every URI. | `ANNA-AX-02`, existing v4/v5 contract suites |
